# Timepicker overview

DHTMLX Timepicker is a component that lets users select time in the 12-hour or 24-hour clock format. Timepicker builds on the Layout and Slider components, so it works as part of any DHTMLX-based application.<br/>
Check [online samples for DHTMLX Timepicker](https://snippet.dhtmlx.com/u9ge1a4z?tag=timepicker).
