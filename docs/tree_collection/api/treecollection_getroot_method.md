# getRoot()

@short: returns the id of the root of the collection

#### Usage

~~~ts
type Id = string | number;
getRoot(): Id;
~~~

@returns:
The id of the root of the collection, which is the parent of the top-level items.

@example:
const rootId = toolbar.data.getRoot();
