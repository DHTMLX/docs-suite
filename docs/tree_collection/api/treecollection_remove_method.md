# remove()

@short: removes an item or several items from the collection

#### Usage

~~~ts
type Id = string | number;
remove(id: Id | Id[]): void;
~~~

@params:
- `id: Id | Id[]` - the id of the item or an array with ids of the items to remove

@example:
toolbar.data.remove("id");
