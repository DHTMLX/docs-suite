This demo shows how to create a hotel management system based on DHTMLX Suite widgets: Layout, Grid, List, Toolbar, Sidebar, and Calendar.

## How to download

Open the [Hotel Management System](https://dhtmlx.com/docs/products/demoApps/dhtmlxHotelManagement/#rooms&date=2021-04-30) demo and click the Download Demo button in the bottom right corner of the page.

Complete the form to start the download. You then receive an email with the download link.

Follow the link in the email to get a free 30-day trial version. You receive a `.zip` file with the hotel management system demo. Save the file and unpack it into your working directory.

The [DHTMLX JavaScript Demos](https://dhtmlx.com/docs/products/demoApps/) page contains more demos.

## How to start

To run the demo, follow the instructions given in the `README.md` file.

## Demo overview

The HTML/JavaScript hotel management system demo shows how to build a hotel management solution with the DHTMLX Suite library.

Grid is one of the main components of the demo. You can add multiline headers and footers, set frozen columns, apply column editors such as a checkbox or combobox, and more. The demo is interactive: try these features and explore the other widgets.

The DHTMLX Optimus framework integrates Layout, Grid, List, Toolbar, Sidebar, and Calendar. The demo has no backend requirements. It is based on the REST API, and you can use any backend platform that supports it, such as PHP, Node.js, .NET, or Java.

For more details, check [GUI for Hotel Management System](https://dhtmlx.com/docs/products/dhtmlxHotelManagement/).
